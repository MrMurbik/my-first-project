# 🎮 Игра «Угадай число» (v2)

Улучшенная версия моей первой игры. Написана на Python.

## 🎯 Правила игры:
- Компьютер загадывает случайное число от 1 до 20.
- Ты вводишь свои варианты в консоль.
- Программа подсказывает, больше загаданное число или меньше.
- В конце игра показывает, за сколько попыток ты угадал.

## 🛡️ Особенности версии:
- Добавлена обработка ошибок (try/except). Теперь, если случайно ввести букву вместо числа, игра не вылетит с ошибкой `ValueError`, а вежливо попросит ввести число еще раз.

## 🚀 Как запустить:
1. Скачай файл `guess_number_v2.py`.
2. Открой терминал в папке с файлом.
3. Выполни команду: `python guess_number_v2.py`

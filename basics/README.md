# 📚 Базовые упражнения

Небольшие скрипты, на которых я отрабатывал основы Python. Это не проекты, а тренировка отдельных тем.

| Файл              | Тема                            |
|-------------------|---------------------------------|
| `01_hello.py`     | вывод текста через `print`      |
| `02_greeting.py`  | переменные, `input`, f-строки   |
| `03_even_odd.py`  | условия `if/else`, оператор `%` |
| `04_countdown.py` | цикл `while`, счётчик           |

## Как запустить

Открой терминал в папке `basics` и выполни команду, подставив нужное имя файла, например: `python 01_hello.py`

## Что я здесь практиковал

- вывод и ввод данных
- переменные и f-строки
- условия `if/else`
- цикл `while` со счётчиком
